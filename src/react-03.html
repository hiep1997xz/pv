useEffect dùng cho đúng
?Dependency array hoạt động ra sao?
?Khi nào KHÔNG nên dùng useEffect?
💡 Trả lời
  • [] chạy một lần sau mount · [a, b] chạy lại khi a hoặc b đổi (so sánh Object.is) · bỏ trống thì chạy sau mọi lần render.
  • Hàm return trong effect là cleanup: chạy trước lần effect kế tiếp và khi unmount. Dùng để huỷ timer, huỷ subscribe, huỷ request.
  • Effect chỉ để đồng bộ với hệ thống bên ngoài (fetch, subscribe, DOM, timer). Dữ liệu suy ra được từ state/props thì tính thẳng lúc render — đừng nhét vào effect.
  • Fetch trong effect bắt buộc chống race condition bằng cờ ignore hoặc AbortController.
useEffect(() => {
  let ignore = false;                    // cờ chống race condition
  fetch(`/api/user/${id}`)
    .then(r => r.json())
    .then(d => { if (!ignore) setUser(d); });

  return () => { ignore = true; };       // cleanup khi id đổi / unmount
}, [id]);
⚠ Bẫy phỏng vấn: Thiếu cleanup là trượt: đổi id nhanh → response cũ về sau response mới → màn hình hiện dữ liệu của user trước đó.
💬 Nói thêm để ghi điểm: Nhắc StrictMode ở React 18 cố tình chạy effect 2 lần trong dev để lộ effect thiếu cleanup — đó là tính năng, không phải bug.
