?useTransition dùng để làm gì?
?Server Component khác Client Component chỗ nào?
💡 Trả lời
  • Concurrent rendering: React có thể tạm dừng hoặc bỏ một lần render đang dở để ưu tiên việc gấp hơn (gõ phím) → UI không bị đơ.
  • useTransition đánh dấu update là không gấp: ô input cập nhật ngay, danh sách nặng render sau. isPending để hiện trạng thái chờ.
  • useDeferredValue hoãn một GIÁ TRỊ thay vì một update — dùng khi bạn không sở hữu hàm set (ví dụ value đến từ props).
  • Suspense: khai báo trạng thái chờ ngay trên cây UI, ghép với lazy() để chia nhỏ bundle.
  • Server Component chạy trên server, không vào bundle, truy cập DB trực tiếp, nhưng không có state / effect / event handler. Client Component có "use client".
const [isPending, startTransition] = useTransition();

function onChange(e) {
  setText(e.target.value);                 // gấp: ô input phản hồi ngay
  startTransition(() => {
    setResults(search(e.target.value));    // không gấp: có thể bị ngắt
  });
}
⚠ Bẫy phỏng vấn: Đừng nói “Server Component để render nhanh hơn”. Ý chính là giảm lượng JS gửi xuống client và lấy dữ liệu sát nguồn, bỏ được một vòng round-trip API.
