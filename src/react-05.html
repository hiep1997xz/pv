💡 Trả lời
  • React.memo bọc component: props không đổi (so sánh nông) thì bỏ qua re-render.
  • useMemo nhớ GIÁ TRỊ trả về của một phép tính nặng. useCallback nhớ chính HÀM, giữ tham chiếu không đổi giữa các lần render.
  • Phải dùng kết hợp: truyền object/array/hàm tạo inline làm props thì React.memo vô hiệu, vì tham chiếu mới mỗi lần render.
  • Tối ưu có giá: tốn bộ nhớ và tốn thời gian so sánh deps. Đo bằng React Profiler trước, đừng bọc bừa cho “chắc ăn”.
const Row = React.memo(function Row({ item, onPick }) { /* ... */ });

// ❌ mỗi render tạo hàm mới → props đổi → React.memo vô dụng
items.map(i => <Row key={i.id} item={i} onPick={() => pick(i.id)} />)

// ✅ tham chiếu ổn định → Row thật sự được bỏ qua
const onPick = useCallback(id => pick(id), []);
items.map(i => <Row key={i.id} item={i} onPick={onPick} />)
⚠ Bẫy phỏng vấn: Hỏi ngược hay gặp: bọc useMemo cho phép tính nhẹ có lợi không? → Không, còn chậm hơn vì phải so sánh deps và giữ giá trị cũ trong bộ nhớ.
💬 Nói thêm để ghi điểm: Nhắc React Compiler (React 19) tự động chèn memo hoá lúc build — xu hướng là bớt tối ưu bằng tay. Biết điều này là rất được điểm.
