Mảng · kỹ thuật two pointer
?Two pointer dùng được khi nào?
?Two-sum trên mảng đã sắp xếp, làm sao tránh O(n²)?
💡 Trả lời
  • Two pointer là hai chỉ số cùng chạy trên một mảng, thay cho hai vòng lặp lồng nhau. Hạ O(n²) xuống O(n) mà vẫn giữ O(1) bộ nhớ.
  • Hai dạng: hai đầu dồn vào giữa (đảo mảng, palindrome, two-sum trên mảng đã sắp xếp) và hai con trỏ cùng chiều (loại trùng, tách chẵn lẻ tại chỗ).
  • Điều kiện của kiểu dồn vào giữa: mảng phải đã sắp xếp. Tổng nhỏ hơn target → kéo l lên cho tổng tăng; lớn hơn → lùi r. Mỗi bước loại hẳn một biên.
  • Loại trùng tại chỗ: con trỏ chậm giữ vị trí ghi, con trỏ nhanh quét; gặp giá trị mới thì ghi vào vị trí chậm rồi tăng. O(n) thời gian, O(1) bộ nhớ.
  • Mảng chưa sắp xếp thì phải sort trước, mất O(n log n) — lúc đó hash map O(n) thường là lựa chọn tốt hơn.
// Đảo mảng TẠI CHỖ — O(n) thời gian, O(1) bộ nhớ
const rev = a => { let l = 0, r = a.length - 1;
  while (l < r) { [a[l], a[r]] = [a[r], a[l]]; l++; r--; } return a; };
console.log(rev([1, 2, 3, 4]));                // [ 4, 3, 2, 1 ]

// Two-sum mảng ĐÃ SẮP XẾP — O(n), O(1) (brute force là O(n²))
function twoSumSorted(a, target) {
  let l = 0, r = a.length - 1;
  while (l < r) {
    const s = a[l] + a[r];
    if (s === target) return [l, r];
    s < target ? l++ : r--;   // thiếu thì kéo trái, thừa thì lùi phải
  }
}
console.log(twoSumSorted([1, 3, 4, 6, 9], 7)); // [ 0, 3 ]
⚠ Bẫy phỏng vấn: Bẫy kinh điển: đề two-sum yêu cầu trả về index của mảng gốc. Bạn sort để dùng two pointer thì index đã xáo trộn, trả ra sai hoàn toàn. Muốn sort thì phải mang index đi kèm, hoặc đổi sang hash map.
💬 Nói thêm để ghi điểm: Nói ra invariant của vòng lặp: “mọi cặp có tổng bằng target đều nằm trong đoạn [l, r]”, nên bỏ một biên là bỏ đúng những cặp chắc chắn sai. Chứng minh được điều này ăn điểm hơn hẳn đọc code.
