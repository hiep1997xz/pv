💡 Trả lời
  • Đo trước khi sửa: @next/bundle-analyzer xem chunk nào to và vì sao · Lighthouse cho LCP/TBT · tab Coverage của DevTools chỉ ra bao nhiêu phần trăm JS tải về mà không hề chạy.
  • Nguyên nhân: import cả thư viện thay vì đúng phần cần · moment kéo theo toàn bộ locale · lodash bản CommonJS không tree-shake được.
  • Không code splitting: mọi màn hình nằm chung một bundle, người dùng mở trang chủ vẫn phải tải code của trang admin. Ảnh gốc vài MB và font tải muộn cũng làm trang đứng hình.
  • Sửa: next/dynamic cho phần nặng ít dùng (editor, chart, modal) · đổi sang date-fns/dayjs · import đúng đường dẫn con · next/image và next/font để preload và chừa chỗ sẵn.
  • Chốt bằng performance budget trong CI: đặt ngưỡng kích thước cho từng chunk, vượt thì fail build. Không có budget thì vài sprint sau bundle lại phình như cũ.
// ❌ kéo nguyên lodash và toàn bộ locale của moment vào client
import _ from 'lodash';
import moment from 'moment';

// ✅ lấy đúng hàm cần, đổi sang thư viện tree-shake được
import debounce from 'lodash-es/debounce';
import { format } from 'date-fns';

// ✅ tách chunk riêng: chỉ tải khi người dùng thật sự mở
const Editor = dynamic(() => import('./Editor'), {
  ssr: false,
  loading: () => <Skeleton />,
});

// đo: ANALYZE=true next build  (@next/bundle-analyzer)
⚠ Bẫy phỏng vấn: Bẫy kinh điển: import { debounce } từ "lodash" vẫn kéo cả gói, vì lodash là CommonJS nên bundler không tree-shake được. Phải dùng lodash-es hoặc import thẳng lodash/debounce.
