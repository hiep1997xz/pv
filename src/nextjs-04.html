💡 Trả lời
  • Không còn getServerSideProps. Next tự suy ra: route chỉ dùng dữ liệu cache được thì render static lúc build; chạm vào dynamic API thì render dynamic mỗi request.
  • Dynamic API gồm cookies(), headers(), searchParams, draftMode(). Next 15 chúng là async, phải await. Ép tay bằng export const dynamic.
  • ISR = static + revalidate: trả bản cũ ngay, nền dựng lại bản mới (stale-while-revalidate). Không phải build lại cả site.
  • generateStaticParams liệt kê trước các [slug] cần prerender. Param ngoài danh sách vẫn render on-demand, trừ khi đặt dynamicParams = false → trả 404.
  • Streaming: loading.tsx hoặc <Suspense> cho phép gửi shell HTML ra trước, phần chậm đẩy xuống sau — TTFB không còn phụ thuộc query chậm nhất.
// app/blog/[slug]/page.tsx
export async function generateStaticParams() {
  const posts = await getTopPosts();
  return posts.map(p => ({ slug: p.slug }));  // ✅ prerender lúc build
}
export const revalidate = 3600;    // ISR: làm mới mỗi giờ
export const dynamicParams = true; // slug lạ vẫn render on-demand

// Streaming: shell ra ngay, phần chậm chờ sau
export default function Page() {
  return <main>
    <Header />
    <Suspense fallback={<Skeleton />}><SlowFeed /></Suspense>
  </main>;
}
⚠ Bẫy phỏng vấn: Lỗi rất hay gặp: bọc <Suspense> nhưng lại await ngay ở component cha rồi mới truyền kết quả xuống → cha bị chặn, streaming thành vô nghĩa. Phần await phải nằm bên trong component đặt dưới Suspense.
