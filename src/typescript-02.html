TypeScript JUNIOR 02 / 08
interface vs type · union · intersection
?Khi nào dùng interface, khi nào dùng type?
?Field optional khác field kiểu undefined ra sao?
💡 Trả lời
  • interface mô tả hình dạng object và merge được: khai trùng tên thì gộp lại. type là bí danh cho mọi kiểu — union, tuple, primitive, mapped type.
  • Chỉ type viết được union. Cả hai đều mở rộng được: interface dùng extends, type dùng intersection &.
  • Quy ước thực dụng: object và props thì interface, còn lại dùng type. Thư viện public nên để interface cho người dùng augment được.
  • Union là “một trong”, intersection là “gộp tất cả”. Union của object chỉ cho đụng field chung, muốn dùng field riêng phải narrow trước.
  • a?: string nghĩa là được phép vắng key. a: string|undefined thì bắt buộc truyền key, chỉ là giá trị được phép undefined. readonly chặn ghi lúc compile.
// interface trùng tên thì merge — type trùng tên thì báo lỗi
interface User { id: string }
interface User { name: string }   // ✅ gộp thành { id, name }

type Status = 'idle' | 'loading' | 'done';   // chỉ type làm được
type Log = { msg: string } & { at: number }; // intersection: gộp cả 2

// ❌ chưa narrow thì không đụng được field riêng của nhánh
function f(v: string | string[]) { return v.toUpperCase(); }

// ✅ narrow xong mới dùng
function g(v: string | string[]) {
  return typeof v === 'string' ? v.toUpperCase() : v.join(',');
}
⚠ Bẫy phỏng vấn: Declaration merging diễn ra âm thầm: hai interface trùng tên trong cùng scope sẽ gộp lại, không một cảnh báo nào; hai type trùng tên thì lỗi ngay. Khá nhiều người tưởng interface cũng báo lỗi.
