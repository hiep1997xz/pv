Coercion · == vs === · falsy
?Kể 7 giá trị falsy trong JavaScript?
?Vì sao [] == false nhưng if([]) lại chạy vào trong?
💡 Trả lời
  • 7 falsy: false, 0 (và -0), 0n, '', null, undefined, NaN. Còn lại truthy hết — kể cả [], {}, '0', 'false'.
  • === không ép kiểu. == khác type thì quy về number, object thì quy về primitive qua valueOf/toString; riêng null và undefined chỉ bằng nhau, không bằng gì khác.
  • Vì sao [] == false: false → 0, [] → '' → 0, thành 0 == 0. Còn if ([]) là ToBoolean — mảng là object nên luôn truthy. Hai phép hoàn toàn khác nhau.
  • NaN !== NaN. Kiểm tra bằng Number.isNaN(x) hoặc Object.is(x, NaN). Object.is giống === trừ hai chỗ: NaN bằng NaN, và +0 khác -0.
  • Toán tử + mà có một vế là string thì nối chuỗi; -, *, / luôn ép về number. Nên '5' + 3 ra '53' còn '5' - 3 ra 2.
console.log('5' + 3);        // '53' — có string thì + là nối chuỗi
console.log('5' - 3);        // 2    — dấu trừ luôn ép về number

console.log([] == false);    // true — [] → '' → 0, false → 0
console.log('' == 0);        // true — '' cũng ép về 0
console.log(Boolean([]));    // true — mảng là object, luôn truthy

console.log(null == undefined);   // true
console.log(null == 0);           // ❌ false — null chỉ bằng undefined
console.log(null >= 0);           // ✅ true  — >= lại ép null thành 0

console.log(NaN === NaN);         // false
console.log(Number.isNaN(NaN));   // ✅ true
console.log(Object.is(+0, -0));   // false — Object.is phân biệt 0 âm
⚠ Bẫy phỏng vấn: Ác nhất là chỗ này: null == 0 là false nhưng null >= 0 là true. Vì == có luật riêng cho null/undefined, còn toán tử so sánh thì ép null về 0.
