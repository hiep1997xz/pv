useEffect chạy vô hạn
?Vì sao useEffect của bạn chạy đi chạy lại không dừng?
?Dependency là object thì React so sánh kiểu gì?
💡 Trả lời
  • Dấu hiệu: tab đơ, tab Network bắn request liên tục, console báo Maximum update depth exceeded.
  • Nguyên nhân số một: dependency là object hoặc hàm tạo mới mỗi render. React so bằng Object.is, tham chiếu mới thì luôn "khác" → effect chạy lại → setState → render → lặp.
  • Nguyên nhân số hai: setState vô điều kiện ngay trong effect không có dependency array — render nào cũng kích hoạt render tiếp theo.
  • Sửa: dữ liệu suy ra được từ state/props thì tính thẳng lúc render. Object cần ổn định thì useMemo, hàm thì useCallback, hằng số thì đưa ra ngoài component.
  • Phòng: bật react-hooks/exhaustive-deps. Nó chỉ đúng dependency còn thiếu, chỗ nào bạn phải "tắt lint" thường chính là chỗ thiết kế sai.
// ❌ options là object mới mỗi render → effect chạy lại vô hạn
const options = { page, size: 20 };
useEffect(() => { load(options); }, [options]);

// ✅ phụ thuộc vào giá trị nguyên thuỷ, dựng object bên trong
useEffect(() => { load({ page, size: 20 }); }, [page]);

// ❌ setState vô điều kiện, không có deps → render → effect → ...
useEffect(() => { setTotal(items.length * 2); });

// ✅ suy ra được từ props/state thì tính thẳng khi render
const total = items.length * 2;
⚠ Bẫy phỏng vấn: Cách sửa sai hay gặp: xoá bớt dependency cho "hết chạy lại". Vòng lặp im thật, nhưng effect bắt đầu đọc giá trị cũ — bạn vừa đổi một bug lộ liễu lấy một bug stale closure khó thấy hơn nhiều.
💬 Nói thêm để ghi điểm: Khoanh vùng nhanh: console.log từng phần tử deps qua 2 lần render, so bằng Object.is — cái nào false liên tục là thủ phạm. React DevTools Profiler cũng chỉ ra vì sao component render lại.
