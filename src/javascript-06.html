Prototype · kế thừa · class
?Prototype chain hoạt động như thế nào?
?__proto__ và prototype khác nhau chỗ nào?
💡 Trả lời
  • Mỗi object có liên kết ẩn tới một object khác. Đọc thuộc tính mà không thấy thì đi tiếp lên trên cho tới khi gặp, hoặc chạm null là dừng. Đó là prototype chain.
  • prototype là thuộc tính của hàm constructor, chứa object sẽ làm prototype cho instance. __proto__ (chuẩn: getPrototypeOf) là liên kết thật của một object.
  • class là syntactic sugar quanh function + prototype: method nằm trên Class.prototype, dùng chung cho mọi instance. Tạo 10.000 instance không nhân bản 10.000 hàm.
  • Nhưng class không chỉ là đường cú pháp: thân class luôn strict, bắt buộc gọi bằng new, method không enumerable, và khai báo không dùng được trước khi chạy tới.
  • extends nối chain; super.m() gọi method lớp cha; trong constructor phải super() trước khi đụng this. instanceof kiểm tra prototype có nằm trên chain không.
class Animal {
  speak() { return 'noise'; }
}
class Dog extends Animal {
  speak() { return super.speak() + ' + woof'; }  // gọi lên lớp cha
}
const d = new Dog();

console.log(d.speak());                  // 'noise + woof'
console.log(d instanceof Animal);        // true — đi theo chain
console.log(Object.getPrototypeOf(d) === Dog.prototype);   // ✅ true
console.log(d.hasOwnProperty('speak'));  // ❌ false — của prototype
console.log(Dog.prototype.hasOwnProperty('speak'));        // ✅ true
// gắn prototype cho object mà không cần constructor:
const o = Object.create({ hi: () => 'hi' });
⚠ Bẫy phỏng vấn: Hỏi vặn: gán obj.__proto__ lúc chạy để "kế thừa động" được không? → Chạy được, nhưng V8 khuyến cáo không làm vậy. Cần đặt prototype thì dùng Object.create hoặc setPrototypeOf ngay lúc khởi tạo.
