?Vì sao nối chuỗi trong vòng lặp hay bị chê?
💡 Trả lời
  • Chuỗi trong JS immutable: không sửa được một ký tự tại chỗ. Mọi thao tác “đổi” đều tạo chuỗi mới, nên luôn tính thêm O(n) bộ nhớ cho kết quả.
  • Đảo chuỗi: [...s].reverse().join("") — O(n). Dùng spread chứ đừng dùng split(""), vì spread tách theo code point nên emoji không bị vỡ.
  • Palindrome: chuẩn hoá trước (thường hoá, bỏ ký tự không phải chữ/số), rồi two pointer từ hai đầu — O(n) thời gian và O(1) bộ nhớ nếu so sánh trực tiếp.
  • Anagram: đúng khi bảng tần suất ký tự giống nhau — O(n) bằng một Map. Cách sort rồi so chuỗi cũng đúng nhưng chậm hơn: O(n log n).
  • Chuỗi con dài nhất không lặp ký tự là bài sliding window + Map lưu vị trí gần nhất — O(n) thời gian, O(k) bộ nhớ với k là số ký tự khác nhau.
// Đảo chuỗi — O(n); chuỗi JS immutable nên bắt buộc tạo chuỗi mới
const rev = s => [...s].reverse().join('');
console.log(rev('algorithm'));                     // mhtirogla

// Palindrome: chuẩn hoá rồi two pointer — O(n) thời gian, O(1) bộ nhớ
function isPal(s, t = s.toLowerCase().replace(/[^a-z0-9]/g, '')) {
  for (let l = 0, r = t.length - 1; l < r; l++, r--)
    if (t[l] !== t[r]) return false;
  return true;
}
console.log(isPal('A man, a plan, a canal: Panama'));   // true

// Anagram: sắp xếp ký tự làm key — O(k log k) cho mỗi từ
const key = s => [...s].sort().join('');
console.log(key('listen') === key('silent'));      // true
⚠ Bẫy phỏng vấn: Bẫy Unicode: "👍".length ra 2 chứ không phải 1, vì JS đếm theo UTF-16 code unit. "👍".split("") cắt emoji thành 2 surrogate rác, đảo xong là hỏng chữ. Dùng [..."👍"] mới đúng 1 phần tử.
