?Route group và dynamic segment dùng khi nào?
💡 Trả lời
  • Mỗi folder trong app/ là một URL segment. Chỉ file tên đặc biệt mới thành route: page.tsx (UI) và route.ts (API). File khác chỉ là colocation, không lộ ra URL.
  • layout.tsx bọc mọi route con và giữ nguyên state khi điều hướng, không remount. Root layout bắt buộc có <html> và <body>.
  • loading.tsx là Suspense boundary tự động cho segment; error.tsx là Error Boundary (bắt buộc Client Component); not-found.tsx hiện khi gọi notFound().
  • (marketing) là route group: gom file và chia layout nhưng không thêm vào URL. Folder bắt đầu bằng _ là private, hoàn toàn không routable.
  • Dynamic segment: [id] một đoạn, [...slug] catch-all, [[...slug]] optional. Next 15: params là Promise, phải await trước khi đọc.
app/
  layout.tsx            // root layout: bắt buộc có <html> và <body>
  (marketing)/          // route group — KHÔNG xuất hiện trong URL
    page.tsx            // ✅ /
  blog/
    layout.tsx          // bọc mọi route con của /blog
    loading.tsx         // Suspense boundary tự động
    [slug]/
      page.tsx          // ✅ /blog/hello
      _components/      // private folder: không routable

// Next 15: params là Promise
export default async function Page({ params }) {
  const { slug } = await params;
}
⚠ Bẫy phỏng vấn: error.tsx KHÔNG bắt được lỗi ném từ layout.tsx cùng cấp, vì boundary nằm bên trong layout đó. Lỗi ở root layout phải dùng global-error.tsx — và file này phải tự render thẻ html, body.
💬 Nói thêm để ghi điểm: Layout không nhận được pathname. Cần biết route hiện tại thì tách một Client Component nhỏ dùng usePathname(), đừng gắn use client cho cả layout.
