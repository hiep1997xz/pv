Dockerfile · Layer cache
?Vì sao COPY package.json phải đứng trước COPY . ?
?Thứ tự lệnh trong Dockerfile ảnh hưởng gì?
💡 Trả lời
  • Mỗi lệnh RUN, COPY, ADD tạo một layer. Docker cache từng layer, và một layer đổi là mọi layer sau nó mất cache.
  • Xếp từ ít đổi đến hay đổi: gói hệ thống → thư viện → mã nguồn. Copy mã nguồn lên trước thì sửa một dòng cũng phải cài lại toàn bộ dependency.
  • Copy package.json rồi npm ci trước, sau đó mới COPY . . — sửa code không làm mất cache của bước cài.
  • .dockerignore phải có node_modules, .git, .env. Vừa nhẹ build context, vừa tránh lộ bí mật vào image.
  • Dọn dẹp phải cùng một layer với lúc cài. Xoá ở layer sau thì file vẫn nằm trong layer trước, image không nhẹ đi chút nào.
FROM node:22-alpine
WORKDIR /app

# ✅ lớp ít đổi nằm trên → sửa code không phải cài lại
COPY package*.json ./
RUN npm ci --omit=dev

COPY . .
CMD ["node", "dist/index.js"]

# ❌ copy hết lên trước → đổi 1 dòng code là npm ci chạy lại
# COPY . .
# RUN npm ci
⚠ Bẫy phỏng vấn: Xoá file ở layer sau không làm image nhẹ đi — layer trước vẫn giữ nguyên file đó. Bí mật lỡ COPY vào rồi RUN rm thì vẫn moi lại được bằng docker history.
💬 Nói thêm để ghi điểm: Phân biệt được CMD và ENTRYPOINT: ENTRYPOINT là lệnh cố định, CMD là tham số mặc định, ghi đè được khi docker run. Luôn dùng dạng mảng để tiến trình nhận được tín hiệu dừng.
