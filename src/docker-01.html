Container vs máy ảo · Image vs Container
?Container khác máy ảo ở điểm nào?
?Image và container khác nhau thế nào?
💡 Trả lời
  • Container không có kernel riêng. Nó dùng chung kernel của host, chỉ bị cô lập bằng namespace (thấy được gì) và cgroup (dùng được bao nhiêu CPU/RAM).
  • Máy ảo phải bật cả một hệ điều hành đầy đủ — nặng vài GB, khởi động vài chục giây. Container chỉ là một tiến trình — vài chục MB, bật trong mili giây.
  • Image là bản đóng gói chỉ đọc, xếp thành nhiều layer. Container = image + một layer ghi được nằm trên cùng.
  • Xoá container là mất sạch layer ghi đó. Thứ gì cần sống lâu hơn container thì phải nằm ở volume.
  • Một image chạy được nhiều container độc lập, và các container dùng chung layer chỉ đọc nên tốn rất ít đĩa.
docker run -d --name web -p 8080:80 nginx:1.27-alpine
docker ps            # container đang chạy
docker images        # image đang có trên máy

# ❌ sửa file trong container rồi tưởng là đã lưu
docker exec -it web sh -c 'echo hi > /tmp/a.txt'
docker rm -f web     # xoá container → mất luôn /tmp/a.txt

# ✅ muốn giữ dữ liệu thì gắn volume vào
docker run -d --name web -v web-data:/data nginx:1.27-alpine
⚠ Bẫy phỏng vấn: Câu vặn hay gặp: container có phải máy ảo siêu nhẹ không? → Không. Nó là tiến trình của host và dùng chung kernel. Nên image Linux không chạy thẳng trên Windows hay macOS — phải có một lớp máy ảo Linux ở giữa.
💬 Nói thêm để ghi điểm: Nêu được ba thứ dựng nên container: namespace cô lập tầm nhìn, cgroup giới hạn tài nguyên, union filesystem xếp layer. Trả lời đúng ba từ này là qua được câu mở màn.
