💡 Trả lời
  • 7 primitive: string, number, boolean, null, undefined, symbol, bigint — lưu theo value. Object / array / function lưu theo reference: biến chỉ giữ địa chỉ.
  • Gán primitive là copy giá trị, hai biến độc lập. Gán object là copy địa chỉ — hai biến trỏ cùng một vùng nhớ, sửa bên này thì bên kia đổi theo.
  • === với object so sánh địa chỉ chứ không so nội dung, nên {a:1} === {a:1} là false. Muốn so nội dung phải tự duyệt hoặc dùng thư viện.
  • Spread {...obj} và Object.assign chỉ copy nông (shallow) — đúng một tầng. Object lồng bên trong vẫn dùng chung reference với bản gốc.
  • Deep clone: structuredClone(obj) (Node 17+, mọi browser hiện đại). Nó không copy được function; còn JSON.stringify thì mất undefined và biến Date thành string.
const a = { x: 1, deep: { y: 2 } };

// ❌ spread chỉ copy 1 tầng: deep vẫn chung reference
const b = { ...a };
b.deep.y = 99;
console.log(a.deep.y);        // 99 — a bị sửa theo

// ✅ structuredClone cắt đứt mọi tầng
const c = structuredClone(a);
c.deep.y = 7;
console.log(a.deep.y);        // 99 — a không đổi

console.log({ x: 1 } === { x: 1 });   // false: khác địa chỉ
⚠ Bẫy phỏng vấn: Câu vặn hay gặp: const có làm object bất biến không? → Không. const chỉ khoá việc gán lại biến; obj.x = 2 và arr.push(1) vẫn chạy bình thường.
💬 Nói thêm để ghi điểm: Object.freeze cũng chỉ đóng băng một tầng. Và khi truyền object vào hàm: sửa thuộc tính thì ảnh hưởng ra ngoài, nhưng gán lại cả tham số thì không — vì JS luôn truyền theo value.
