Connection pool · Rò rỉ connection
?App chạy vài tiếng rồi mọi request treo, nghi gì đầu tiên?
?Pool size nên đặt bao nhiêu và dựa vào đâu?
💡 Trả lời
  • Mở một connection tới Postgres là TCP handshake + xác thực + fork một process phía server — tốn hàng chục ms. Pool giữ sẵn N connection, query xong thì trả lại chứ không đóng.
  • Pool size không phải càng to càng tốt. Mỗi connection là một process của Postgres; tổng pool của mọi instance phải nhỏ hơn max_connections. Khởi đầu cỡ số core × 2 rồi đo.
  • Connection leak: lấy bằng pool.connect() nhưng nhánh throw không gọi release() → pool cạn dần, request sau xếp hàng rồi timeout. Luôn release() trong finally.
  • connectionTimeoutMillis = chờ mượn connection bao lâu thì bỏ cuộc (chống treo vô hạn). idleTimeoutMillis = connection rảnh bao lâu thì đóng, trả tài nguyên lại cho DB.
  • Serverless: mỗi instance có pool riêng, scale lên 200 instance là 200 pool → nổ max_connections ngay. Đặt PgBouncer ở giữa để gom lại thành một pool chung.
// pg — một Pool dùng chung cả app: import { Pool } from 'pg'
export const pool = new Pool({
  max: 20,                    // tổng mọi instance < max_connections
  idleTimeoutMillis: 30_000,      // connection rảnh 30s thì đóng
  connectionTimeoutMillis: 5_000, // chờ mượn quá 5s thì báo lỗi
});

// ❌ throw ở giữa → connection này không bao giờ quay về pool
const c = await pool.connect();
await c.query('UPDATE ...');   // câu này ném lỗi là rò rỉ luôn
c.release();

// ✅ release trong finally, chạy cả khi throw
const c2 = await pool.connect();
try { await c2.query('UPDATE ...'); } finally { c2.release(); }
⚠ Bẫy phỏng vấn: Quên release() ở nhánh lỗi là bug kinh điển: chạy dev không thấy gì, lên production vài giờ thì mọi request treo ở connectionTimeoutMillis. Dấu hiệu nhận ra: pool.idleCount về 0 còn pool.waitingCount tăng đều.
💬 Nói thêm để ghi điểm: Query đơn lẻ thì dùng thẳng pool.query() — pg tự mượn và tự trả connection, không thể rò rỉ. Chỉ cần pool.connect() khi làm transaction hoặc khi nhiều câu bắt buộc đi trên cùng một connection.
