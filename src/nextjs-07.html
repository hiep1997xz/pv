4 tầng cache của Next.js
?Next có mấy tầng cache, mỗi tầng nằm ở đâu?
?revalidateTag xoá được những tầng cache nào?
💡 Trả lời
  • 1. Request Memoization — sống trong một lần render của một request. Dedupe fetch GET trùng URL để nhiều component cùng gọi mà chỉ đi mạng một lần. Render xong là mất.
  • 2. Data Cache — trên server, sống qua nhiều request và qua cả deploy. Chứa kết quả fetch đã opt-in cache. Xoá bằng hết hạn revalidate, revalidateTag hoặc revalidatePath.
  • 3. Full Route Cache — server giữ HTML + RSC Payload của route static. Route dynamic không có tầng này. Data Cache revalidate thì HTML dựng lại; deploy mới là xoá sạch.
  • 4. Router Cache — nằm trong bộ nhớ trình duyệt, theo phiên, giữ RSC Payload theo segment để back/forward mượt. Bấm F5 là mất sạch.
  • Xoá Router Cache bằng router.refresh(), hoặc Server Action có gọi revalidateTag/revalidatePath. Next 15 hạ mặc định staleTimes.dynamic về 0.
// Tầng            Ở đâu     Sống bao lâu       Xoá bằng
// 1 Request Memo    server    1 lần render       tự hết
// 2 Data Cache      server    qua nhiều request  revalidateTag/Path
// 3 Full Route      server    tới khi revalidate revalidate, deploy
// 4 Router Cache    browser   phiên làm việc     refresh(), F5

// Server Action: xoá tầng 2 + 3, đồng thời báo client bỏ tầng 4
'use server';
export async function publish(id) {
  await db.post.publish(id);
  revalidateTag('posts');     // Data Cache + Full Route Cache
  revalidatePath('/blog');    // thêm: xoá theo đúng path
}
⚠ Bẫy phỏng vấn: Bẫy hay gặp nhất: sửa dữ liệu, gọi revalidateTag trong Route Handler, server đã có bản mới nhưng user bấm Back vẫn thấy bản cũ. Vì Router Cache nằm ở browser — gọi từ Server Action hoặc router.refresh() mới xử lý được.
