keyof · typeof · indexed access · mapped
?keyof và typeof kết hợp với nhau thế nào?
?Mapped type dùng để làm gì trong thực tế?
💡 Trả lời
  • keyof T cho ra union các key của T. typeof obj ở vị trí type thì rút type từ một giá trị đang có — khác hẳn typeof lúc runtime.
  • Ghép hai thứ lại: keyof typeof config lấy đúng danh sách key của object thật, khỏi phải khai lại union chuỗi bằng tay rồi quên đồng bộ.
  • Indexed access T[K] lấy type của field. T[keyof T] ra union mọi giá trị, Arr[number] ra type phần tử của mảng hoặc tuple.
  • Mapped type [K in keyof T] duyệt từng key để dựng type mới. Có modifier readonly và ?, gỡ bằng -readonly và -?.
  • Template literal type ghép chuỗi ngay ở tầng type: từ click dựng ra onClick. Ghép với mapped type và as để đổi tên key lúc map.
const config = { host: 'localhost', port: 5432, ssl: false };

type Key = keyof typeof config;    // 'host' | 'port' | 'ssl'
type Val = (typeof config)[Key];   // string | number | boolean

// mapped type: gỡ readonly và gỡ optional của mọi field
type Mutable<T> = { -readonly [K in keyof T]-?: T[K] };

// đổi tên key ngay lúc map bằng as + template literal
type Handlers<T> = {
  [K in keyof T as `on${Capitalize<K & string>}`]: (v: T[K]) => void;
};

// Handlers<{ id: string }>  →  { onId: (v: string) => void }
⚠ Bẫy phỏng vấn: Đừng lẫn hai typeof: ở vị trí giá trị nó trả chuỗi lúc runtime, ở vị trí type nó rút type lúc compile. Và keyof trên object có index signature string sẽ ra string | number, không phải union key cụ thể.
